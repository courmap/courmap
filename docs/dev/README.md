# Developer notes

Working notes for the people and agents building Courmap. They are not user documentation (that is the site under `site/`).

- `HANDOFF.md`: where the build stands and what is next. Read it first in a new session.
- `LAUNCH.md`: everything open before the public launch, with owners and checks. Update it at the end of every session.
- `SESSION-*.md`: what one session did and what it left for the next.

`docs/SPEC.md` (scope and data model) and `docs/DECISIONS.md` (choices the spec left open) stay one level up, in `docs/`.
