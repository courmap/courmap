# data/seeds

Generated by `pnpm seed` (packages/seed). Committed, never hand-edited. To fix a seeded work, add a short override file under `data/works/` with the same id.

- `works-000.jsonl` to `works-015.jsonl`: one seeded work per line, in the `works/` format plus an `origin` object. A work's shard is a hash of its slug.
- `manifest.json`: the exact upstream pins (cedya77 release tag, Anime-Lists commit) with SHA-256 checksums, shard checksums, and coverage counts.
- `relations/`, `airing/`, `tmdb-splits/`: what the bots write, one JSON file per work (`<work-id>.json`, `origin: bot`), so that two bot PRs never touch the same file. The seed job leaves them alone.
- `slugs.jsonl`: every slug ever assigned, by AniDB ID. Published slugs are never renamed or reused.
- `conflicts.jsonl`: seed data that was dropped or defaulted, and why.

Rerunning `pnpm seed` with the pins in `manifest.json` reproduces these files byte for byte.
