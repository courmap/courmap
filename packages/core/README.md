# @courmap/core

The engine behind [@courmap/client](https://www.npmjs.com/package/@courmap/client): the data model, title normalization, the alias index, and the translate, lookup, resolve and search operations over any `Dataset`. Most users want `@courmap/client` instead, which builds on this.

Documentation: [courmap.pages.dev](https://courmap.pages.dev/). Code: Apache-2.0. Repository: [github.com/courmap/courmap](https://github.com/courmap/courmap).
